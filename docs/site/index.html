DisAHRsterRadio
FunktionenMitmachenDemoGitHub

Funk statt Funkloch.
Fürs Ahrtal.

DisAHRsterRadio ist ein offline LoRa-Mesh-Messenger auf Basis von MeshCore. Wenn Internet und Mobilfunk ausfallen, reichen kleine 868-MHz-Funkboards Textnachrichten von Knoten zu Knoten weiter. Das Handy verbindet sich per WLAN mit dem Board und nutzt die Oberfläche MeshAhrtal – ganz ohne App-Store, Handynetz oder Gebühren.

Live-Demo im Browser ansehen Releases Code auf GitHub

Was es kann

💬

Chat und Direktnachrichten

Kanäle und private Nachrichten über Funk, mit Empfangsbestätigung und Warteschlange, wenn der Empfänger gerade nicht erreichbar ist.

🆘

Schwarzes Brett und Schnellmeldungen

Hilfe gesucht, Hilfe angeboten, Info – mit Ort und Ablaufzeit. Ein Tipp für Trinkwasser, Strom, Medikamente oder „Mir geht es gut“.

📍

Standort teilen

Ortsliste, Karte oder GPS-Modul; kompakt, nur auf Knopfdruck und in wählbarer Genauigkeit.

🗺️

Offline-Karten

Ahrtal von der Quelle bis zur Mündung, Ortsdetails, Versorgungspunkte aus OpenStreetMap und eigene Orte – auf dem Handy gespeichert.

📡

Repeater und Room-Server

Repeater auf Höhen tragen Nachrichten durchs Tal, ein Room-Server hält das Schwarze Brett für später Hinzukommende bereit.

🔓

Offen und lokal

Open Source (MIT), keine Cloud, keine Konten. Läuft auf LILYGO T3-S3 (SX1262/SX1276), LILYGO T3 V1.6.1 (TTGO) und Heltec V2.

So einfach geht’s

  1. Board aufstellen

    Funkboard mit Antenne und Strom – zu Hause, im Auto oder auf dem Dach.

  2. Handy verbinden

    Mit dem WLAN DisAHRsterRadio-… verbinden und 192.168.4.1 öffnen.

  3. Schreiben

    Nachricht oder Meldung senden – das Mesh reicht sie weiter.

So sieht es aus

Mitmachen

🏠

Knoten aufstellen

Jeder zusätzliche Knoten verdichtet das Netz in deiner Straße und deinem Ort.

⛰️

Repeater auf Höhen

Standorte auf Hügeln, Türmen und Dächern verbinden die Orte im Tal.

🧪

Testen

Reichweite messen, die Demo ausprobieren und Fehler als Issue melden.

⌨️

Code und Doku

Firmware, Web-Oberfläche, Karten und Anleitungen auf GitHub verbessern.
