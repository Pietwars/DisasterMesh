# Ahrtal-Foto

`ahrtal-night.jpg` ist die unveränderte, vom Nutzer bereitgestellte Datei IMG_1469.jpeg (76.533 Bytes). Die andere Bildvorlage mit MeshAhrtal-Schrift dient als Stilreferenz; ihr QR-Code und ihre Schrift sind nicht Bestandteil des Fotos im Portal.

Quellenhinweis in der Oberfläche: Pietwars. Das bereitgestellte Foto wird nicht pauschal unter die MIT-Lizenz des Programmcodes gestellt. Es ist für die angeforderte MeshAhrtal-Gestaltung eingebaut.

`tools/web_assets.py` bettet CSS und Foto in die Firmwareseite und die portable Demo ein. Das Foto wird im CSS einmal als Daten-URI definiert; die mobile und Desktop-Gestaltung teilen diese Daten.
